# QLKH-FE

Website quản lý kho hàng đơn giản bằng HTML/CSS/JavaScript thuần.

## Tính năng

- Thêm/cập nhật sản phẩm theo mã hàng
- Quản lý tồn kho với thao tác nhập (+1) và xuất (-1)
- Tìm kiếm nhanh theo mã hoặc tên hàng
- Thống kê tổng mặt hàng, tổng số lượng, giá trị tồn và hàng sắp hết
- Lưu dữ liệu trên trình duyệt bằng `localStorage`

## Chạy dự án

Mở trực tiếp file `index.html` trong trình duyệt.
